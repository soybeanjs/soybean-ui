# SoybeanUI v0.50.0 重构方案

> 定位：v0.50.0 版本的**原地重构总方案**——逻辑层改名 aria、依赖最小化、准入整改执行、日期与表格/表单引擎更换。给维护者与执行 Agent 看。
> 状态：💡 提案（⚠️ 已与品牌改名 VBean 合并为同一次 breaking 发布，见 [rebrand-vbean.md](./rebrand-vbean.md)）
> 基线：2026-09-11 · 分支：v0.40.0（当前版本 v0.40.0-beta.1）
> 决策来源：ubean-ui 重构实验仓（`/Users/soybean/Web/Projects/SoybeanJS/ubean-ui/docs`，migration / dependencies / architecture / aria-admission-remediation）。ubean-ui 是「fork 重建」实验；本方案是把其实验结论**落回本仓执行**（改名后语境以 [rebrand-vbean.md](./rebrand-vbean.md) 为准）。
> 组件规范：[`.agents/skills/soybean-ui-develop/`](../.agents/skills/soybean-ui-develop/SKILL.md)。准入规则正文以 skill `layers.md` 为准，本文只做**执行编排**。

> **重大变更（2026-09-11）**：(1) **品牌级改名 SoybeanUI → VBean 与 v0.50.0 合并为同一次 breaking 发布**（[rebrand-vbean.md](./rebrand-vbean.md) §8），命名维度以该文档为唯一权威——逻辑层 `headless → @vbean/aria`（原本案只换层名 `aria`、scope 不变，已被其升级覆盖）。以下凡出现 `@vbean/*` 均按改名后语境。(2) **外围包 `ui-x` / `admin` / `chart` 已整包移除**（v0.40.0 起）：AI/chat 组件回核心 headless/ui（[ui-ai-roadmap.md](./ui-ai-roadmap.md)）、admin shell 回核心（[ui-shell-roadmap.md](./ui-shell-roadmap.md)）、charts 仅存文档站示例（TanStack Charts）。因此本文不再有「保留外围包分层」议题（原 §2.2、§8 已据此改写）。其余核心库重构议题（依赖最小化、准入整改、日期与 Table/Form 引擎更换等）不受影响。

## 2. 改名：品牌级改名（headless → `@vbean/aria`）

> **已升级为品牌级改名**：v0.50.0 发布时同步执行 SoybeanUI → VBean 品牌改名（[rebrand-vbean.md](./rebrand-vbean.md)），整个命名维度（npm scope、CLI、运行时契约 `data-soybean-*` / `--soybean-*`、域名、仓库）以该文档为唯一权威。本文原「headless → `@soybeanjs/aria`、scope 不变」的映射已被其升级覆盖，本节只收录重构本身仍相关的层名最小集合。

「aria」准确表达该层职责（ARIA 语义、键盘、焦点、a11y 状态机），与「无样式 headless」的泛称相比合同更清晰；ubean 实验已验证该命名（品牌级改名后为 `@vbean/aria`）。

## 4. Aria 准入整改执行

准入规则正文（R1–R8 两段式 Gate 1/Gate 2）以 skill `layers.md` 为准；既有清单见 [headless-admission-remediation.md](./headless-admission-remediation.md)（v0.50.0 改名 `aria-admission-remediation.md` 并更新状态）。本节编排**执行顺序与家族级定论**。

### 4.1 Drawer 独立 aria 家族 + BottomSheet 退役

现状：headless 无 drawer 家族——[UI SDrawer](../packages/ui/src/components/drawer/drawer.vue) 直接 compose `DialogCompact`；`bottom-sheet` 是完整 headless 家族，含 `use-snap-points.ts`、`use-scale-background.ts`、Confirm/Cancel/Compact。

定论（2026-09-01 ubean 决策反转，本仓跟进）：snap points、swipe 进度、拖拽手柄、嵌套缩放是 Dialog 不具备的真实领域状态机，「Drawer = Dialog with a side」定位作废。

执行：

1. 新建 `packages/aria/src/components/drawer/`：Root / Trigger / Portal / Overlay / Content / Handle / Close / Title / Description / SwipeArea / Viewport（+ 嵌套 Nested 钩子）。
2. 以现 `bottom-sheet` 的 `use-snap-points` / `use-scale-background` 为**复用基底**（同源自 vaul），对照 reka-ui Drawer 补齐：swipe dismiss（轴锁定 / 方向阻尼 / 速度采样 / 滚动让位）、`v-model:snapPoint`、modal 三层级（`true` / `'trap-focus'` / `false`）；横向 side 首版声明「仅纵向 snap」。
3. scale background / fadeFromIndex 作为 opt-in composable + prop 保留（bottom-sheet 行为合同转 Drawer 测试用例）。
4. `SDrawer` 从 compose Dialog 改为 compose Drawer 原语；`SBottomSheet` 退役，Confirm/Cancel/Footer 由 UI 层组合 Drawer 实现。
5. 验收：bottom-sheet 的 e2e / 单测行为合同（snap 吸附、swipe 关闭、scale background）全部在 drawer 有对位测试；`pnpm sui gen catalog aria` 重生成。

### 4.2 Card 改判 UI-only（HAD-C4）

- 删除 `packages/aria/src/components/card/`（含 `CardCompact` 与全部原语、`@vbean/aria/card` 子路径）。
- `SCard` 重写：`CollapsibleRoot`（`defaultOpen: true`）+ 自绘 header/titleRoot/title/description/footer + `CollapsibleContent` / `CollapsibleTrigger`；`provideCollapsibleUi` 注入 recipe 的 root/content/trigger 子集；自绘节点保留 `data-vbean-card-*`（品牌级改名后）。
- `styles/card.ts`、`CardUiSlot`、`ui` 覆盖语义不变；docs 与示例改引用。

### 4.3 解剖壳与薄壳下沉

| 家族       | 定论                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `empty`    | 删除 aria 家族；Empty 做 UI-only（组合已有 Primitive / Icon）                                                                          |
| `list`     | 删除家族；纯列表用 HTML + UI class；交互列表走 `listbox` / `tree`                                                                      |
| `skeleton` | 下沉 UI-only（与 spinner 同类）                                                                                                        |
| `badge`    | 下沉 UI-only；可关闭能力组合 Button/Icon                                                                                               |
| `tag`      | 下沉 UI-only；可关闭标签交互以 `tags-input` 为准；顺手修正 headless 组件名泄漏（`defineOptions({ name: 'STag' })` 不得出现在 aria 层） |
| `alert`    | **保留 aria 家族但补语义**：必须带 `role="alert"` / `status` 与关闭 `aria-label`，禁止只搬 `open` + `div`                              |

### 4.4 NavigationMenu 移除

## 5. 日期引擎（date-fns + Date）

新建 `packages/aria/src/date/`（替换现基于 `@internationalized/date` 的实现）：

- **值模型**：日历日 `Date`（本地 00:00）或 `{ date: Date, time?: Date }`；range 为 `{ start: Date | null, end: Date | null }`。**不**暴露 `CalendarDate` / `ZonedDateTime`，不做长期适配层。
- 日历网格、segment、parse、format 全部基于 `date-fns` + `Intl.DateTimeFormat`；数字格式化走 `Intl.NumberFormat`。
- 组件面不变：Calendar / CalendarRange / DateField / DateRangeField / TimeField / TimeRangeField / DatePicker / DateRangePicker。
- 第一期只做 local date；Zoned/时区需求单独立项，不偷偷加回 CalendarDate。
- **迁移对照文档**（中英）：`CalendarDate` → `Date` 值映射、format/parse 对照、range 写法对照，进 docs content。

## 6. Table / Form 引擎（TanStack）

**Table**

- 引擎换 `@tanstack/vue-table`：column defs、sorting、filtering、expanding、column pinning/sizing 以 TanStack 命名为第一公民；旧 `TableColumn.dataIndex` / `sortState` 可提供薄别名映射到 `accessorKey` / `SortingState`，但不做兼容层。
- aria 层只保留：table/grid 角色、`aria-sort`、键盘导航、虚拟滚动（`@tanstack/vue-virtual`）、Compact 装配。
- UI 层：样式、筛选弹层、resize handle。
- 服务端 `request`、查询工具栏、列管理面板不进核心第一期；Pro 能力以可选 composable 在 table 目录导出，保持 tree-shake，不建外围 table 包。

**Form**

- 引擎换 `@tanstack/vue-form`：字段级订阅、字段数组、提交生命周期；删除自研 `useHeadlessForm` 与 klona 提交拷贝路径。
- aria 层只保留 `Form` / `Field` / `Label` / `Control` / `Description` / `Error` 的 id 接线与 `aria-invalid` / `aria-describedby`、Compact 装配。
- Schema：消费者传入 Standard Schema 兼容对象（Zod/Valibot），库不运行时依赖 `@standard-schema/spec`。
- 错误进出场动画移到 UI 层 `<Transition>`（配合 [§3](#3-依赖最小化) auto-animate 移除）。
- Schema→UI 自动渲染不进 v0.50.0；若做，作为可选组件独立目录后议。

## 8. Tree-shake 验收（核心包）

**外围包现状：`ui-x` / `admin` / `chart` 已整包移除**（v0.40.0 起），原「与 ubean 刻意偏差、保留外围包分层」议题不复存在：

- `ui-x`：AI/chat 组件回核心 headless/ui（见 [ui-ai-roadmap.md](./ui-ai-roadmap.md)）；`markstream-vue` 2.x 改为 `@vbean/ui` 的**直接依赖**（仅 UI 包，不进 aria 层），`shiki` / `mermaid` / `katex` 为可选 peer，缺失时优雅降级。
- `admin`：shell 组件回核心（见 [ui-shell-roadmap.md](./ui-shell-roadmap.md)，headless `shell/` + `SLayoutShell` / `SPageHeader` 等）。
- `chart`：charts 仅存文档站示例（[TanStack Charts](https://tanstack.com/charts)，`apps/docs/src/examples/chart/`），不进核心依赖树。

v0.50.0 的 tree-shake 要求全部落在**核心包**：

1. `@vbean/aria` / `@vbean/ui` 的 `exports` 含 `.` 与 `./{component}` 子路径。
2. `sideEffects` 精确到 CSS / UnoCSS include；barrel 无副作用初始化；组件 SFC 无模块级 `window` 监听。
3. bundle fixture（W5）：`import { SButton } from '@vbean/ui'` 产物不含 table / form / date-fns / embla 代码（markstream 属 UI 可选渲染底座，仅经 `SMarkdown` 显式引用时进入产物）。
4. AI/chat 的 `markstream-vue` 不得进入 aria 层；aria 运行时依赖遵守 §3.2 白名单。

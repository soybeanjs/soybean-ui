# SoybeanUI v0.50.0 重构方案

> 定位：v0.50.0 版本的**原地重构总方案**——逻辑层改名 aria、依赖最小化、准入整改执行、日期与表格/表单引擎更换。给维护者与执行 Agent 看。
> 状态：💡 提案
> 基线：2026-09-10 · 分支：v0.40.0（当前版本 v0.40.x）
> 决策来源：ubean-ui 重构实验仓（`/Users/soybean/Web/Projects/SoybeanJS/ubean-ui/docs`，migration / dependencies / architecture / aria-admission-remediation）。ubean-ui 是「fork 重建」实验；本方案是把其实验结论**落回 soybean-ui 本仓**，品牌与包体系保持 soybean 不变。
> 组件规范：[`.agents/skills/soybean-ui-develop/`](../.agents/skills/soybean-ui-develop/SKILL.md)。准入规则正文以 skill `layers.md` 为准，本文只做**执行编排**。

> **2026-09 勘误：本提案写作时 `@soybeanjs/ui-x` 仍在仓内；其后 ui-x 已整包移除，AI/chat 组件改为在核心 headless/ui 内重新实现（见 [ui-ai-roadmap.md](./ui-ai-roadmap.md)）。** 因此 §2.2 改名步骤、§8「保留外围包分层」及其 tree-shake 论据中与 ui-x 相关的内容均已失效；admin / chart 相关条目同属历史（v0.40.0 已移除）。其余核心库重构议题（aria 改名、依赖最小化、引擎更换等）不受影响。

| NavigationMenu      | **v0.50.0 移除**（原计划 v1.0；借改名+引擎大版本窗口提前）；唯一导航菜单家族为 `nav-menu`                                                                                                                                                                                                         |

| 浮层背景 a11y       | **已完成**：自研 `shared/mark-others.ts`（Base UI 方案：inert 优先 + WeakMap 引用计数 + aria-live 豁免 + `data-soybean-inert` 标记通道）+ `composables/use-hide-others.ts`，不依赖 `aria-hidden` 包                                                                                               |

| 外围包              | **保留 `ui-x` / `admin` / `chart` 分层**（与 ubean 决策不同，见 [§8](#8-tree-shake-与外围包策略)）；核心包 tree-shake 验收照做                                                                                                                                                                    |

| 消费者 CLI          | 不变：`sbean`（init/add/build/diff/mcp）与仓库生成器 `sui` 保持双 CLI；`sui` 子命令跟随改名                                                                                                                                                                                                       |

v0.50.0 是含 breaking change 的 minor（0.x 阶段允许）：不提供 `@soybeanjs/headless` 兼容导出，不承诺 1:1 旧 API；日期值模型与 Table/Form API 必须提供迁移对照文档。

## 2. 改名：`@soybeanjs/headless` → `@soybeanjs/aria`

「aria」准确表达该层职责（ARIA 语义、键盘、焦点、a11y 状态机），与「无样式 headless」的泛称相比合同更清晰；ubean 实验已验证该命名。

### 2.1 命名映射

| 现状                                          | v0.50.0                                                                                                                     |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `packages/headless/`                          | `packages/aria/`                                                                                                            |
| `@soybeanjs/headless`                         | `@soybeanjs/aria`                                                                                                           |
| `@soybeanjs/headless/shared`                  | `@soybeanjs/aria/shared`                                                                                                    |
| `@soybeanjs/headless/date`                    | `@soybeanjs/aria/date`                                                                                                      |
| `@soybeanjs/headless/composables` 等子路径    | 同名跟随                                                                                                                    |
| `@soybeanjs/headless/nuxt`、`./resolver`      | `@soybeanjs/aria/nuxt`、`@soybeanjs/aria/resolver`                                                                          |
| namespaced `Headless.AccordionRoot`           | `Aria.AccordionRoot`（`packages/aria/src/namespaced/index.ts` 生成）                                                        |
| `pnpm sui gen catalog headless`               | `pnpm sui gen catalog aria`（[scripts/src/index.ts](../packages/scripts/src/index.ts) 命令面与帮助文本）                    |
| docs content `content/{en,zh}/headless/`      | `content/{en,zh}/aria/`                                                                                                     |

**不改**：`S` 组件前缀、`data-soybean-{family}-{slot}` 属性、`--soybean-*` CSS 变量、`sbean` / `sui` 二进制名、`@soybeanjs/*` npm scope、UI 包名 `@soybeanjs/ui`、theme / ui-uno / sbean 包名。

### 2.2 执行步骤（建议一个 PR 完成，不做机械改名的长期分支）

1. 目录重命名 `packages/headless` → `packages/aria`；`package.json` name 改 `@soybeanjs/aria`；exports 子路径同步。
2. 全仓 import 路径替换：`@soybeanjs/headless` → `@soybeanjs/aria`（约 373 个 ts/vue 文件，覆盖 packages/ui、ui-x、admin、chart、apps/docs、apps/nuxt）。

4. Nuxt 模块与 resolver 改名（`aria/nuxt`、`aria/resolver`）；ui / ui-x / admin / chart 包内注册逻辑同步。
5. docs：`content/{en,zh}/headless` → `aria`；menus 分组值；examples 中引用 `Headless.*` 的 demo（如 hover-card）改 `Aria.*`。
6. skill 7 文件 + AGENTS.md + docs 整改清单文件改名与内容替换。
7. 重生成：`pnpm sui gen api` + `pnpm sui gen api --translate --locale zh`、`pnpm sui gen changelog`（+ 翻译）。
8. 验收：`pnpm build`（构建顺序 libs → aria → ui → ui-x → admin → chart → sbean）、`pnpm typecheck`、`pnpm test`、`pnpm test:e2e` 全绿；`grep -r "@soybeanjs/headless" packages apps` 为 0。

## 3. 依赖最小化

### 3.2 `@soybeanjs/aria` 运行时依赖目标白名单

- `vue`（peer）
- `@floating-ui/dom`
- `@tanstack/vue-virtual`
- `@tanstack/vue-table`、`@tanstack/vue-form`（table/form 引擎）
- `date-fns`

## 4. Aria 准入整改执行

准入规则正文（R1–R8 两段式 Gate 1/Gate 2）以 skill `layers.md` 为准；既有清单见 [headless-admission-remediation.md](./headless-admission-remediation.md)（v0.50.0 改名 `aria-admission-remediation.md` 并更新状态）。本节编排**执行顺序与家族级定论**。

### 4.1 Drawer 独立 aria 家族 + BottomSheet 退役

现状：headless 无 drawer 家族——[UI SDrawer](../packages/ui/src/components/drawer/drawer.vue) 直接 compose `DialogCompact`；`bottom-sheet` 是完整 headless 家族，含 `use-snap-points.ts`、`use-scale-background.ts`、Confirm/Cancel/Compact。

定论（2026-09-01 ubean 决策反转，本仓跟进）：snap points、swipe 进度、拖拽手柄、嵌套缩放是 Dialog 不具备的真实领域状态机，「Drawer = Dialog with a side」定位作废。

执行：

1. 新建 `packages/aria/src/components/drawer/`：Root / Trigger / Portal / Overlay / Content / Handle / Close / Title / Description / SwipeArea / Viewport（+ 嵌套 Nested 钩子）。
2. 以现 `bottom-sheet` 的 `use-snap-points` / `use-scale-background` 为**复用基底**（同源自 vaul），对照 reka-ui Drawer 补齐：swipe dismiss（轴锁定 / 方向阻尼 / 速度采样 / 滚动让位）、`v-model:snapPoint`、modal 三层级（`true` / `'trap-focus'` / `false`）；横向 side 首版声明「仅纵向 snap」。
3. scale background / fadeFromIndex 作为 opt-in composable + prop 保留（bottom-sheet 行为合同转 Drawer 测试用例）。
4. `SDrawer` 从 compose Dialog 改为 compose Drawer 原语；`SBottomSheet` 退役，Confirm/Cancel/Footer 由 UI 层组合 Drawer 实现。
5. 验收：bottom-sheet 的 e2e / 单测行为合同（snap 吸附、swipe 关闭、scale background）全部在 drawer 有对位测试；`pnpm sui gen catalog aria` 重生成。

### 4.2 Card 改判 UI-only（HAD-C4）

- 删除 `packages/aria/src/components/card/`（含 `CardCompact` 与全部原语、`@soybeanjs/aria/card` 子路径）。
- `SCard` 重写：`CollapsibleRoot`（`defaultOpen: true`）+ 自绘 header/titleRoot/title/description/footer + `CollapsibleContent` / `CollapsibleTrigger`；`provideCollapsibleUi` 注入 recipe 的 root/content/trigger 子集；自绘节点保留 `data-soybean-card-*`。
- `styles/card.ts`、`CardUiSlot`、`ui` 覆盖语义不变；docs 与示例改引用。

### 4.3 解剖壳与薄壳下沉

| 家族       | 定论                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `empty`    | 删除 aria 家族；Empty 做 UI-only（组合已有 Primitive / Icon）                                                                          |
| `list`     | 删除家族；纯列表用 HTML + UI class；交互列表走 `listbox` / `tree`                                                                      |
| `skeleton` | 下沉 UI-only（与 spinner 同类）                                                                                                        |
| `badge`    | 下沉 UI-only；可关闭能力组合 Button/Icon                                                                                               |
| `tag`      | 下沉 UI-only；可关闭标签交互以 `tags-input` 为准；顺手修正 headless 组件名泄漏（`defineOptions({ name: 'STag' })` 不得出现在 aria 层） |
| `alert`    | **保留 aria 家族但补语义**：必须带 `role="alert"` / `status` 与关闭 `aria-label`，禁止只搬 `open` + `div`                              |

### 4.4 NavigationMenu 移除

## 5. 日期引擎（date-fns + Date）

新建 `packages/aria/src/date/`（替换现基于 `@internationalized/date` 的实现）：

- **值模型**：日历日 `Date`（本地 00:00）或 `{ date: Date, time?: Date }`；range 为 `{ start: Date | null, end: Date | null }`。**不**暴露 `CalendarDate` / `ZonedDateTime`，不做长期适配层。
- 日历网格、segment、parse、format 全部基于 `date-fns` + `Intl.DateTimeFormat`；数字格式化走 `Intl.NumberFormat`。
- 组件面不变：Calendar / CalendarRange / DateField / DateRangeField / TimeField / TimeRangeField / DatePicker / DateRangePicker。
- 第一期只做 local date；Zoned/时区需求单独立项，不偷偷加回 CalendarDate。
- **迁移对照文档**（中英）：`CalendarDate` → `Date` 值映射、format/parse 对照、range 写法对照，进 docs content。

## 6. Table / Form 引擎（TanStack）

**Table**

- 引擎换 `@tanstack/vue-table`：column defs、sorting、filtering、expanding、column pinning/sizing 以 TanStack 命名为第一公民；旧 `TableColumn.dataIndex` / `sortState` 可提供薄别名映射到 `accessorKey` / `SortingState`，但不做兼容层。
- aria 层只保留：table/grid 角色、`aria-sort`、键盘导航、虚拟滚动（`@tanstack/vue-virtual`）、Compact 装配。
- UI 层：样式、筛选弹层、resize handle。
- 服务端 `request`、查询工具栏、列管理面板不进核心第一期；Pro 能力以可选 composable 在 table 目录导出，保持 tree-shake，不建外围 table 包。

**Form**

- 引擎换 `@tanstack/vue-form`：字段级订阅、字段数组、提交生命周期；删除自研 `useHeadlessForm` 与 klona 提交拷贝路径。
- aria 层只保留 `Form` / `Field` / `Label` / `Control` / `Description` / `Error` 的 id 接线与 `aria-invalid` / `aria-describedby`、Compact 装配。
- Schema：消费者传入 Standard Schema 兼容对象（Zod/Valibot），库不运行时依赖 `@standard-schema/spec`。
- 错误进出场动画移到 UI 层 `<Transition>`（配合 [§3](#3-依赖最小化) auto-animate 移除）。
- Schema→UI 自动渲染不进 v0.50.0；若做，作为可选组件独立目录后议。

## 8. Tree-shake 与外围包策略

**与 ubean 的刻意偏差：保留 `ui-x` / `admin` / `chart` 外围包分层。** ubean 作为新线选择「全部进 `@ubean/ui` + 子路径导出」；本仓外围包已发布且依赖隔离有真实价值——`ui-x` 的 `markstream-vue`（markdown/mermaid/shiki）、`chart` 的 `@unovis/*` 都是重依赖，独立包保证它们不会进入核心组件使用者的依赖树（ADR-0001 的分层结论继续有效）。

v0.50.0 对 tree-shake 的要求落在**核心包**：

1. `@soybeanjs/aria` / `@soybeanjs/ui` 的 `exports` 含 `.` 与 `./{component}` 子路径。
2. `sideEffects` 精确到 CSS / UnoCSS include；barrel 无副作用初始化；组件 SFC 无模块级 `window` 监听。
3. bundle fixture（W5）：`import { SButton } from '@soybeanjs/ui'` 产物不含 table / form / date-fns / embla / markstream。
4. 外围包（ui-x/admin/chart）跟随改名 `@soybeanjs/headless` → `@soybeanjs/aria` 引用，包名与 `Sx` / `SApp*` / `SChart*` 前缀不变。

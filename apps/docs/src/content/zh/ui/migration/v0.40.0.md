# 升级指南：v0.30.0 → v0.40.0

v0.40.0 是一次收敛型发布：外围包下线、headless 层彻底不再注入样式、上下文助手改名并收紧语义。下面逐条列出破坏性变更及其迁移方式。

## 1. 外围包下线

`@soybeanjs/ui-x`、`@soybeanjs/admin`、`@soybeanjs/chart` 不再发布。三者都已发布到 `0.30.0`，因此如果你依赖其中任意一个，要么锁定旧版本，要么按下表迁移。

| 包                 | 状态                                                                                                                                                             | 能力去向                                                                                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `@soybeanjs/ui-x`  | 移除（20 个 `Sx*` AI 组件）                                                                                                                                      | 在 `@soybeanjs/headless` + `@soybeanjs/ui` 内以标准 `S` 前缀重新实现 — 见 AI 组件路线图。`v0.40.0-beta.1` 尚未提供。                                         |
| `@soybeanjs/admin` | 移除（此前只有骨架，未交付组件）                                                                                                                                 | 以核心内 **shell 领域**（`SLayoutShell`、`SPageHeader` 等）回归 — 见壳组件路线图。无需迁移。                                                                 |
| `@soybeanjs/chart` | 移除（`SChartContainer`、`SChartTooltipContent`、`SChartLegendContent`、`SChartStyle`、`chartColors`、`chartThemes`、`componentToString`、`buildChartColorCss`） | 图表明确**不进核心库**。文档站的图表示例直接构建在 [TanStack Charts](https://tanstack.com/charts) 上；想要同样的效果可参考 `apps/docs/src/examples/chart/`。 |

```bash
# 移除已下线的包
pnpm remove @soybeanjs/ui-x @soybeanjs/admin @soybeanjs/chart
```

```diff
- import { SxBubble, SxSender } from '@soybeanjs/ui-x';
- import { SChartContainer } from '@soybeanjs/chart';
```

暂时无法去掉的，可以锁定最后发布的版本：

```json
{
  "dependencies": {
    "@soybeanjs/ui-x": "0.30.0",
    "@soybeanjs/chart": "0.30.0"
  }
}
```

## 2. headless：移除 `RovingFocusGroup` / `RovingFocusItem` 组件

这两个 SFC 原语已从 `@soybeanjs/headless` 移除（根导出、`./roving-focus` 子路径、`Headless.*` 命名空间都不再有）。能力改由 composable 提供，渲染什么元素完全由你决定：

```diff
- <RovingFocusGroup orientation="horizontal" :loop="true">
-   <RovingFocusItem v-for="tab in tabs" :key="tab" as-child>
-     <button>{{ tab }}</button>
-   </RovingFocusItem>
- </RovingFocusGroup>
+ <script setup lang="ts">
+ import { toContext } from '@soybeanjs/headless/shared';
+ import { useRovingFocusGroup, useRovingFocusGroupItem } from '@soybeanjs/headless/composables';
+
+ const { setContainerElement, groupProps } = useRovingFocusGroup(
+   toContext({ orientation: 'horizontal', loop: true })
+ );
+ </script>
+
+ <template>
+   <div :ref="setContainerElement" v-bind="groupProps">
+     <button v-for="tab in tabs" :key="tab" v-bind="useRovingFocusGroupItem().itemProps">
+       {{ tab }}
+     </button>
+   </div>
+ </template>
```

`useRovingFocusGroup` 返回 `{ setContainerElement, groupProps, getOrderedItems }`，`useRovingFocusGroupItem` 返回 `{ setItemElement, itemProps }`。参数是响应式的（`ToContext` 形状），从 props 构造时用 `toContext(props, [...])`；`itemProps` 已经带好 `tabindex`、collection 属性、orientation 数据属性与键盘事件处理。

## 3. headless：上下文助手改名并调整语义

```diff
- import type { PropsToContext } from '@soybeanjs/headless/types';
- import { transformPropsToContext } from '@soybeanjs/headless/shared';
+ import type { ToContext } from '@soybeanjs/headless/types';
+ import { fromContext, toContext } from '@soybeanjs/headless/shared';
```

改名是机械替换，但 `toContext` 的语义也变了：`transformPropsToContext` 会对函数值**自动调用**（`typeof v === 'function' ? v() : v`），而 `toContext` 原样保存值，函数在上下文里仍然是函数。

```ts
// 之前：`renderIcon: () => VNode` 这类 prop 进上下文时已被调用，取到的是 VNode。
// 现在：取到的仍是函数本身。
const context = toContext(props, ['renderIcon']);
context.renderIcon.value(); // 在消费处显式调用
```

`fromContext(context, keys)` 是新增的配套函数：把 `toContext` 生成的映射快照回普通值，并且容忍 nullish 上下文（在 `defu` 兜底链里很方便）。

## 4. headless：`ConfigProviderContext` 改为普通值

上下文类型从「每键一个 ComputedRef」变成 props 的只读快照：

```diff
- export interface ConfigProviderContext
-   extends PropsToContext<Omit<ConfigProviderProps, 'iconRender'>>,
-     Pick<ConfigProviderProps, 'iconRender'> {}
+ export type ConfigProviderContext = Readonly<ConfigProviderProps>;
```

如果你直接消费这个上下文，去掉 `.value`：

```diff
- const context = useConfigProvider();
- const dir = computed(() => context?.dir?.value ?? 'ltr');
+ const context = useConfigProvider();
+ const dir = computed(() => context?.dir ?? 'ltr');
```

Provider 现在使用共享注入 key（`Symbol.for('ConfigProvider')`），模块图中出现重复的 `@soybeanjs/headless` 副本时不再丢失查找。方向解析也多了一级：显式 `dir` → `ConfigProvider` 的 `dir` → **由 `locale` 推导方向** → `ltr`。

## 5. headless：不再注入全局类名

`SConfigProvider` 此前会注入一段 `<style>`，若干 headless 部件也硬编码了这些类名。现在两者都已移除 — headless 组件真正做到零样式：

| 移除的类名                            | 替代                                   |
| ------------------------------------- | -------------------------------------- |
| `soybean-headless-scrollbar-hidden`   | `scrollbar-none`（来自 UnoCSS preset） |
| `soybean-headless-overflow-y-hidden`  | `overflow-y-hidden`                    |
| `soybean-headless-transition-all-150` | `transition-all duration-150`          |
| `soybean-headless-opacity-0`          | `opacity-0`                            |
| `soybean-headless-scale-0`            | `scale-0`                              |
| `soybean-headless-sr-only`            | `sr-only`                              |

带样式的包装层已经带好等价类名（例如 `SScrollArea` 的 viewport 使用 `scrollbar-none`），所以多数使用者无感。如果你**直接使用 headless 原语**并依赖注入的 CSS，需要自己补上：

```diff
- <ScrollAreaViewport class="soybean-headless-scrollbar-hidden">
+ <ScrollAreaViewport class="scrollbar-none">
```

滚动条隐藏由 `@soybeanjs/ui-uno` 提供的 `scrollbar-none` 工具类承担（来自新增的 `presetScrollbar`，默认已包含在 `presetUiUnocss()` 中）。如果你只用 headless 而不引入该 preset，请自行提供对应规则。

## 6. ui：`STable` 默认不再圆角

```diff
- <STable :data="rows" />          {/* 之前是圆角 */}
+ <STable :data="rows" rounded />  {/* 需要圆角请显式开启 */}
```

`rounded` 的默认值改为 `false`，与其他表面组件「圆角按需开启」的约定保持一致。

## 7. `@soybeanjs/ui-uno`：动画 preset 内置

不再依赖 `unocss-preset-animations`，该能力已内置并直接导出：

```diff
- import UnocssPresetAnimations from 'unocss-preset-animations';
- export default defineConfig({ presets: [presetUiUnocss(), UnocssPresetAnimations()] });
+ import { presetAnimations, presetScrollbar } from '@soybeanjs/ui-uno';
+ export default defineConfig({ presets: [presetUiUnocss()] }); // 两者已默认包含
```

`presetUiUnocss()` 签名不变，但新增了透传选项 — `wind3`、`animations`、`scrollbar`、`webFonts`、`preflights` — 并额外导出 `buildGlobalCss`、`buildThemeColors`、`resolveWind3Dark`。新增的 `presetScrollbar` 提供 `scrollbar-none`（见第 5 节），默认已启用。`UiUnocssOptions` / `SbeanPresetOptions` 类型仍然导出，既有配置无需改动。

## 8. 依赖清理（通常无感）

- `@nuxt/kit` 与 `@nuxt/schema` 不再是 `@soybeanjs/headless` 的 `peerDependencies`，Nuxt 模块接线已内聚。
- `@soybeanjs/headless` 移除或内联了 11 个运行时依赖（`@soybeanjs/hooks`、`@soybeanjs/utils`、`defu`、`klona`、`fuse.js`、`ohash`、`aria-hidden`、`@floating-ui/utils`、`@vueuse/shared`、`@dnd-kit/helpers`、`embla-carousel-reactive-utils`）。如果你的应用**没有显式声明**就直接 import 了它们（依赖 pnpm 提升），请把它们加进自己的 `package.json`。
- 仅贡献者相关：`packages/_shared` 改名为 `packages/shared` 并转为源码分发（`#shared/*` 子路径导入）。

## 这次能拿到什么

- **Popper 原地重构完成。** 定位原语新增 `PopperTrigger`、`PopperPortal`、`PopperSub` / `PopperSubTrigger`、`PopperCompact`、延时分组与 `useVirtualPointReference`，全部沿用既有 `Popper*` 命名 — 旧的 root/anchor/positioner/popup/arrow 用法无需改动。
- **新增导航组件**：`SNavMenu`、`SSplitNav`、`STreeNav`（以及对应 headless 原语）。
- **主题持久化无闪烁**：`createThemeInitScript({ injectCss: true })` 会在首屏绘制前从 `THEME_CSS_STORAGE_KEY` 回放派生 CSS。
- **路由感知的链接**：`SConfigProvider` 新增 `linkComponent`，所有 `SLink` / `SButtonLink` 可统一走 `RouterLink` / `NuxtLink`，无需逐处传参。

## 升级检查清单

1. `pnpm remove @soybeanjs/ui-x @soybeanjs/admin @soybeanjs/chart`（或锁定 `0.30.0`）。
2. `PropsToContext` → `ToContext`、`transformPropsToContext` → `toContext`；检查函数型上下文值。
3. 用 composable 替换 `RovingFocusGroup` / `RovingFocusItem`。
4. 去掉 `ConfigProviderContext` 消费处的 `.value`。
5. 直接使用 headless 原语的地方，替换 `soybean-headless-*` 类名。
6. 需要圆角的 `STable` 补上 `rounded`。
7. 从 UnoCSS 配置中移除 `unocss-preset-animations`。
8. 显式声明此前依赖提升才 import 到的传递依赖。

# Internationalization

## Overview

UI-X components are locale-aware and integrate with the same i18n system used by `@soybeanjs/ui`.

## Message Keys

UI-X uses the `sx.` prefix for its i18n keys. Each component provides keys for:

- Loading states
- Placeholder text
- Action labels (copy, like, dislike, etc.)
- Aria labels for accessibility

## Setup

Configure `vue-i18n` with the UI-X locale messages:

```ts
import { createI18n } from 'vue-i18n';

const i18n = createI18n({
  locale: 'en',
  messages: {
    en: {
      // ...UI messages
      sx: {
        copy: 'Copy',
        copied: 'Copied!',
        like: 'Like',
        dislike: 'Dislike'
        // ...
      }
    },
    'zh-CN': {
      sx: {
        copy: '复制',
        copied: '已复制！',
        like: '点赞',
        dislike: '踩'
      }
    }
  }
});
```

## RTL Support

All UI-X components support RTL (right-to-left) layouts through the same direction system as `@soybeanjs/ui`. Bubble placement, conversation layout, and action positioning automatically flip in RTL mode.

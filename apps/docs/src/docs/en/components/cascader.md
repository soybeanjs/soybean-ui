# Cascader

## Overview

A cascader (cascade selection) component for selecting values from hierarchical tree data. It renders a linked multi-column panel, supports single/multiple selection, full-path value mode, parent-child check state propagation, local filtering and remote search, lazy loading of children and virtual scrolling for large datasets.

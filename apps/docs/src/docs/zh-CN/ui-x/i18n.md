# 国际化

## 概述

UI-X 组件具备区域感知能力，与 `@soybeanjs/ui` 使用相同的 i18n 系统。

## 消息键

UI-X 使用 `sx.` 前缀作为 i18n 键。每个组件提供以下键：

- 加载状态
- 占位文本
- 操作标签（复制、点赞、踩等）
- 无障碍 ARIA 标签

## 配置

使用 `vue-i18n` 配置 UI-X 区域消息：

```ts
import { createI18n } from 'vue-i18n';

const i18n = createI18n({
  locale: 'zh-CN',
  messages: {
    en: {
      sx: {
        copy: 'Copy',
        copied: 'Copied!',
        like: 'Like',
        dislike: 'Dislike'
      }
    },
    'zh-CN': {
      sx: {
        copy: '复制',
        copied: '已复制！',
        like: '点赞',
        dislike: '踩'
      }
    }
  }
});
```

## RTL 支持

所有 UI-X 组件通过 `@soybeanjs/ui` 的方向系统支持 RTL（从右到左）布局。气泡位置、会话布局和操作按钮定位在 RTL 模式下会自动翻转。
